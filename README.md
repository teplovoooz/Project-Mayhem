# TSU Лекции Бот

Автоматизация входа на лекции в систему e-class.tsu.ru

## Возможности

- ✅ Автоматический вход на мероприятие по ID
- ✅ Ввод ФИО автоматически
- ✅ Остаток в аудитории определённое время
- ✅ Веб-интерфейс для управления
- ✅ Логирование всех действий
- 🚧 Планирование запуска по времени (в разработке)

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python web_app.py
```

Откройте браузер: http://localhost:5000

## Структура

- `bot.py` - основной класс бота для автоматизации
- `web_app.py` - Flask приложение с веб-интерфейсом
- `templates/index.html` - интерфейс
- `config.json` - конфиг с ФИО и настройками
- `logs.txt` - логи действий

## Использование

1. Заполните ФИО в настройках
2. Введите ID мероприятия
3. Укажите время (минуты)
4. Нажмите "Запустить"

Бот автоматически:
- Откроет браузер
- Зайдёт на сайт
- Введёт данные
- Останется в аудитории на указанное время
- Закроется
